SCOPE
================================================================================

1. **Accumulate across selections.** Append newly chosen files to the existing list rather than
   replacing it. Sketch, not a prescription:

       onChange={e => {
         const picked = Array.from(e.target.files ?? []);
         setFiles(prev => mergeWithinLimit(prev, picked));
         e.target.value = '';        // let the SAME file be re-picked after removal
       }}

   **That `e.target.value = ''` matters** - without it, re-selecting a file you just removed fires
   no `change` event and looks broken.

2. **De-duplicate.** Same name + size + lastModified = same file; do not add it twice. Picking a
   folder twice must not double every entry.

3. **Per-file removal.** An x on each listed file. This is what makes accumulation usable; without
   it a wrong pick still forces starting over.
