### Why we are adding, not migrating

Full migration was considered and rejected on two findings from the LiteLLM docs:

1. **LiteLLM does not host skill content.** The registry stores only a pointer:
   `{"source":{"source":"git-subdir","url":"https://github.com/org/repo","path":"..."}}`.
   Claude Code clones from that URL — and **both our repos are private**
   (`cogniziocompany/cognizioware-mcp-tools`, `cogniziocompany/ptait09-easybutt0n-ai`),
   so every consumer would need git credentials.
2. **The registry is Claude Code-only.** Cursor, Codex, ChatGPT, curl and Open WebUI reach
   skills today *only* through MCP prompts — which was the entire design rationale
   ("no local skill loader needed").

So: **one canonical SKILL.md, two publication channels.** The MCP-prompt catalog stays the
source of truth for all clients; the Skill Hub becomes an additional Claude Code-facing view.
