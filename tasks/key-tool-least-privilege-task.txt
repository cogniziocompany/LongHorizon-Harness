### The guiding principles these sets are derived from

1. **Least privilege** - a role gets only what its JOB needs, not what might be handy.
2. **The auditor NEVER writes.** Its whole value is independent verification; a writing auditor cannot
   be trusted to judge its own effects.
3. **Scope by `mcp_access_groups`, never by server ID** - IDs regenerate on config change and silently
   turn an ID-scoped key deny-all.
4. **Never `["*"]`.**
5. **Every tool schema is re-sent on EVERY call in the round**, so the set size is a recurring cost,
   not a one-off. Small sets are cheaper AND safer - the two goals align here.
6. **Scope by WORKSPACE too, not one global set.** A powerplatform task needs `pac` + `xrm`; an
   mcp-tools task does not. A single union set pays for every namespace on every call.

### Proposed sets - a STARTING POINT to validate, not a decision

    kb (7)  +  kbuat (7)  +  hydra (7, read)  +  postgres (9, read-only queries)
