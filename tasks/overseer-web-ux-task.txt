182a  SCHEMA + API (fleet-admin/schema.sql + src/server.js, applied by src/migrate.js):
  fleet.overseer_sessions   (id, name, short_ref, transcript_path, started_at, last_seen_at, host)
  fleet.handoffs            (id, key UNIQUE, title, body_md, source_session, target, status[open|acknowledged|
                             queued|superseded|closed], created_by, created_at, acknowledged_at, ack_token,
                             repo, branch, run_ids text[], langfuse_trace_ids text[], artifact_paths text[])
  fleet.asks                (id, handoff_id NULL, kind[CREDENTIAL|SPEND|PROD_WINDOW|DECISION], question_md,

  fleet.ask_messages        (id, ask_id, author[paxton|overseer|session:<ref>], body_md, created_at)  -- the chat
  fleet.ledger_rows         (id, ts, session, body_md, task_ids text[], run_ids text[], key UNIQUE)
  fleet.task_state          (task_id, state ∈ the eleven states + HELD/BLOCKED/FAILED/SUPERSEDED, evidence_md,
                             verified_at, updated_by, updated_at)   -- task 119's table, made real

  semantics as the harness queue's dedup_key.

  POST /api/overseer/asks/:id/answer, GET/POST /api/overseer/ledger, GET/PUT /api/overseer/tasks/:id/state.
  socket.io /fleet events: handoff.created, ask.updated, ledger.appended (follow _emit at server.js ~L312).
