Research findings to build on (overseer, 2026-09-06; cite these URLs in the doc): Open WebUI persists `ConfigVar` settings in its database after first launch (`ENABLE_PERSISTENT_CONFIG`, default true) — later env changes are ignored unless persistent config is disabled, and a stable `WEBUI_SECRET_KEY` + Redis (`REDIS_URL`, `WEBSOCKET_REDIS_URL`) are required for restart-safe sessions (https://docs.openwebui.com/reference/env-configuration/ , https://taylorwilsdon.medium.com/the-sres-guide-to-high-availability-open-webui-deployment-architecture-2ee42654eced , https://docs.openwebui.com/faq/); Pipelines are legacy — in-process Functions (Pipes, Filters, Actions) and Tools cover the use cases (https://docs.openwebui.com/features/extensibility/plugin/ , https://docs.openwebui.com/features/extensibility/pipelines/); native MCP support is Streamable-HTTP only since v0.6.31, and OpenAPI tool servers / mcpo remain the recommended enterprise path (https://docs.openwebui.com/features/extensibility/mcp/ , https://docs.openwebui.com/features/extensibility/plugin/tools/openapi-servers/mcp/); YouTrack integrations with AI agents follow "repo-aware automation + structured write-back to custom fields" (https://youtrack-support.jetbrains.com/hc/en-us/community/posts/35639869921426-Youtrack-integrate-with-AI-agents).
