  update_spend 155, flush_gateway_requests 153, ProxyConfig.add_deployment 82,

  matching clean|spendlog|retention returns nothing).
The container started 2026-09-17T20:55:48Z = 13:55 PT, which PREDATES the #493 write at ~16:10 PT.
LiteLLM registers the spend-log cleanup at STARTUP from config; `ProxyConfig.check_periodic_reloads`
reloads config values every 30 s but does NOT register new scheduler jobs. So a live
`/config/update` can never start this job.
